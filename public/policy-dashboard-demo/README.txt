HEALTH AI POLICY DASHBOARD — NAVIGABLE DEMO

Open index.html in any modern web browser. No installation or local server is required.

Demonstrated flow:
1. Module B: default world map landing view
2. Module A: methodology and framework
3. Select Rwanda / View details
4. Switch between Level 1, Level 2, and Document Repository
5. Search, filter by category, and sort the country repository
6. Open the sample document analysis drawer and cited-passage viewer
7. Module C: reactively filter and search sample instruments

All policy content and counts are illustrative placeholders for interface testing.
The external “Innovator Insights” link opens the current main site.

Map boundaries are derived from Natural Earth 1:110m Admin 0 country data
(public domain) and are embedded locally in assets/world-map.svg.
